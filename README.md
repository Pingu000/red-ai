# Red-AI — Autonomous Web Pentesting Agent

> AI-powered autonomous web auditing agent for dynamic application security testing.
> Developed as a Final Year Project in Software Engineering (Cybersecurity specialization).

---

## What is it?

**Red-AI** is a DAST (Dynamic Application Security Testing) agent that combines local LLMs with real pentesting tools to perform web audits autonomously. The agent reasons about the target, selects tools, analyzes results, and adapts its strategy on each iteration — without human intervention.

Designed for lab environments and test applications with explicit permission. Do not use against systems without authorization.

---

## Tech stack

- **Orchestration:** [LangGraph](https://github.com/langchain-ai/langgraph)
- **Local LLM:** [Ollama](https://ollama.com) (`qwen2.5-coder:14b` / `qwen2.5-coder:32b`)
- **UI:** [Streamlit](https://streamlit.io)
- **Runtime OS:** Kali Linux
- **Integrated tools:** `nmap`, `gobuster`, `sqlmap`, `nikto`, `curl`

---

## Agent workflow

1. **Reconnaissance** — nmap to detect open ports and services
2. **Enumeration** — gobuster for directories and files (two passes: no extension + `.asp/.php/.html`)
3. **Exploration** — curl to analyze forms and endpoints
4. **Exploitation** — sqlmap and nikto on discovered attack vectors
5. **Report** — final report automatically generated by the LLM

The agent maintains a history of findings and visited URLs to avoid repeating actions, and stops when it emits `AUDITORIA_COMPLETA` or after 50 iterations.

## Installation

```bash
git clone https://github.com/Pingu000/red-ai.git
cd red-ai
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

**Prerequisites:**
- Kali Linux (or any distro with the required tools installed)
- [Ollama](https://ollama.com) running with a model loaded
- `nmap`, `gobuster`, `sqlmap`, `nikto` installed

---

## Configuration

By default the agent connects to Ollama at `http://localhost:11434`. If Ollama is running on a different machine (e.g. a Windows host from a VM), set:

```bash
export OLLAMA_HOST=http://<host-ip>:11434
```

---

## Usage

**Dashboard (recommended):**
```bash
source venv/bin/activate
streamlit run frontend/app.py
```

**CLI:**
```bash
python run.py --objetivo http://target.com --modelo qwen2.5-coder:14b
```
